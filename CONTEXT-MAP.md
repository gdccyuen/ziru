# Context Map

This repo has two domain contexts. Read the glossary for the context you're working in.

- **core/** — the knowledge engine and account domain (Ziru API, Celery worker, shared Python library). Glossary: `core/CONTEXT.md`. Decisions: `core/docs/adr/`.
- **webui/** — the WebUI workspace/chat domain. Glossary: `webui/CONTEXT.md`.

System-wide engineering skills configuration: `docs/agents/`.
